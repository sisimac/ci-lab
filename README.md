# ci-lab

Учебная песочница: Playwright + GitHub Actions.

## Что где лежит

| Путь | Что это |
|---|---|
| `app/index.html` | Мини-приложение «Список задач» — объект тестирования |
| `tests/todo.spec.ts` | Тесты пользовательских сценариев |
| `playwright.config.ts` | Настройки: три браузера, автозапуск приложения, отчёты |
| `.github/workflows/playwright.yml` | Пайплайн GitHub Actions |
| `.vscode/settings.json` | Чтобы расширение Playwright видело нужную переменную |
| `node_modules/` | Зависимости **и браузеры** (~1.5 ГБ) |

## Команды

```bash
npm run test:ui        # визуальный режим — основной способ работы
npm test               # прогон в терминале, все три браузера
npm run test:chromium  # только chromium, быстрее
npm run report         # открыть HTML-отчёт последнего прогона
npm run app            # поднять приложение отдельно (http://127.0.0.1:5173)
```

Приложение поднимать вручную не нужно: Playwright делает это сам перед прогоном.

## Как удалить всё

Браузеры лежат внутри проекта (`PLAYWRIGHT_BROWSERS_PATH=0`), поэтому:

```bash
rm -rf ~/dev/ci-lab
```

Это удаляет всё: код, зависимости, браузеры, отчёты. В системных папках macOS ничего не остаётся.

Опционально, если захочется вычистить совсем начисто:

```bash
rm -rf ~/Library/Caches/ms-playwright   # общий кэш браузеров, если что-то уехало мимо
```

Node.js установлен отдельно (`/usr/local/bin/node`) и этим проектом не затрагивается.
